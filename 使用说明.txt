========================================
 奶龙光标 · Nailong Cursor
 Windows 鼠标指针主题
========================================

【安装】

 1. 右键 install.inf → 选择「安装」
    弹出「用户账户控制」时点「是」（要把文件复制到 C:\Windows\Cursors，需要管理员权限）

 2. 打开鼠标设置：
    控制面板 → 鼠标 → 「指针」选项卡
    （Win10/11 也可以：设置 → 蓝牙和其他设备 → 鼠标 → 其他鼠标选项 → 「指针」选项卡）

 3. 在「方案」下拉框里选「Nailong Cursor」→ 点「应用」→「确定」

 完成。


【为什么装完没变化？】

 第 1 步只是把方案「注册」进系统，第 2~3 步手动选一下才会真正生效 ——
 这是 Windows 鼠标指针方案的机制，所有指针主题包都是这个流程。

 如果第 3 步的下拉框里找不到「Nailong Cursor」，
 说明第 1 步没成功，重做一次，注意 UAC 一定要点「是」。


【卸载】

 1. 在鼠标属性里把「方案」换回「Windows 默认（系统方案）」，确定
 2. 删除文件夹 C:\Windows\Cursors\Nailong Cursor


【包含的指针】

 Arrow        正常选择
 Help         帮助选择
 AppStarting  后台运行   （动画）
 Wait         忙碌       （动画）
 Crosshair    精确选择
 IBeam        文本选择
 NWPen        手写
 No           不可用
 SizeNS       垂直调整
 SizeWE       水平调整
 SizeNWSE      对角调整 ↖↘
 SizeNESW      对角调整 ↗↙
 SizeAll      移动
 UpArrow      候选
 Hand         链接选择
 Pin          位置选择
 Person       人员选择

 每个指针都打包了 32 / 48 / 64 / 96 / 128 / 192 / 256 七档尺寸，
 系统会按你的屏幕缩放比例和「鼠标指针大小」设置自动挑最合适的一档，
 高分屏下不会发虚。


【小提示】

 · 指针大小可以在 设置 → 蓝牙和其他设备 → 鼠标 → 鼠标指针大小 里调，
   调大调小都是同一套图，不会失真。
 · 想换回经典箭头：鼠标属性 → 方案 → 选「Windows 默认（系统方案）」。
